### get started

To start the application, just open the index.html file. That's it.

### how to

<li>add waypoints to the map by left click in the map</li>
<li>to move a waypoint to a new point, you can drag and drop the marker by a left mouse click</li>
<li>removing waypoints works by selecting a waypoint by a left mouse click on the marker and use the "remove waypoint" button, you can also remove a waypoint by right clicking on the marker in a quicker way</li>
<li>Input parameters are taken over from previous waypoints as default, except the coordinates</li>
<li>changes for a waypoint must be submitted by clicking the "update waypoint" button</li>
<li>the data can be send to a server by using the "send waypoints to server" button, the host can be edited in the index.html file by changing the constant "ns.c.apiEndpoint" -> at the moment the data is send to "ns.c.apiEndpoint" + "/dronedata".</li>
